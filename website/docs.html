Known fork gaps vs the upstream docs

  • Browser extension is unpacked, not on the stores (yet); use the native messaging key (integration@misterdownloadmanager.com) with an unpacked install.
  • Installer tooling checks pwsh, rpmbuild, dpkg-deb — make sure before tools/installer/build-linux.sh.
  • Updates: self-update is disabled in the fork; use your distro's package or cargo install --path crates/app again.
